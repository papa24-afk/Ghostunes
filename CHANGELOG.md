## [1.0.0] - 2026-10-26

### Added
- **Core Music Engine:** High-performance YouTube Music streaming proxy using InnerTube catalog extraction.
- **Synchronized Lyrics:** Integrated LRCLIB and community synced lyrics providers with interactive seekable karaoke view and plain-text fallback.
- **Offline Storage & SQLite Persistence:** Full download pipeline supporting HTTP Range chunk requests, pause/resume capability, duplicate check, and SQLite track/playlist manifests.
- **Smart Autoplay Radio:** Intelligent recommendation engine with 4 user-selectable modes (`similar`, `artist`, `discover`, `balanced`).
- **Library Management:** Custom playlist creation, track reordering, persistent favorites, and listening history with data export/import.
- **Cross-Platform Playlist Importer:** Reconciliation importer for Spotify, Apple Music, Deezer, and YouTube playlists.
- **Desktop System Integration:** Electron 45 desktop shell with Windows SMTC lock screen and keyboard media transport controls.
- **Personalization:** Wallpaper customization, blur filters, GhostSkin themes, and OLED true-black dark mode.
- **Audio Lab & Listening Rooms:** Parametric EQ, loudness normalization, and synchronized collaborative playback rooms.
- **Community Infrastructure:** GitHub Actions CI, contributor documentation, issue templates, and security reporting policy.
